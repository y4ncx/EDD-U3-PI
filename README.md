# 📂 Analizador de Archivos Numericos con Pilas y Colas

Este es un proyecto en **Java** que analiza una lista de números desde un archivo de texto, mostrando resultados como:

- 🔹 **Valor mínimo, máximo y promedio**
- 🔹 **Orden manual** (usando pila y cola)
- 🔹 **Orden nativo** de Java para comparación

---

## ⚙️ Tecnologías

- ☕ **Java 21**
- 🧱 **Estructuras de datos:** Pila (`Stack`) y Cola (`Queue`)

---

## 🧠 Descripción breve

El programa compara dos métodos de ordenamiento:
- El **orden manual**, implementado con estructuras de datos.
- El **orden nativo**, usando las herramientas internas de Java.

Esto permite analizar el comportamiento, eficiencia y funcionamiento práctico de las pilas y colas en un caso real.
